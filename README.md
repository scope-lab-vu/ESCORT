## :gear: Configurations
**Install Dependencies:**
```bash
chmod +x install_dependencies.sh
./install_dependencies.sh
chmod +x install_atari_roms.sh
./install_atari_roms.sh
```

**Install Python3.14:**
```bash
python3.14 -m venv escort_venv
```
